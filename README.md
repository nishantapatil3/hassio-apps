# Home Assistant apps

This repository contains Home Assistant apps (formerly called add-ons).

## Installation

Add this repository URL in **Settings > Apps > App store > Repositories**:

```text
https://github.com/nishantapatil3/hassio-apps
```

## Apps

- [LiteLLM](litellm/) — an OpenAI-compatible AI gateway configured for
  OpenRouter, NVIDIA NIM, Claude Code, and Claude Desktop.
- [PostgreSQL](postgres/) — PostgreSQL 18 database service.
- [Redis](redis/) — Redis in-memory data store.
- [Prometheus](prometheus/) — monitoring and time-series storage for Home Assistant.
- [SearXNG](searxng/) — a privacy-respecting metasearch engine.
- [Hermes Agent](hermes/) — a self-improving AI agent with Home Assistant and messaging gateway support.
- [Jaeger](jaeger/) — OpenTelemetry-compatible distributed tracing backend and UI.
